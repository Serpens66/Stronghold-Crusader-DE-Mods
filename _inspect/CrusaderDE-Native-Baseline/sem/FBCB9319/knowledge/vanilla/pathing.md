# Pathfinding, routes and unit movement [Scope: Vanilla]

Native hash FBCB9319 (full hash in [CURRENT.json](../../../../CURRENT.json)). Summary state 2026-11-27. Check the installed DLL hash per [CURRENT.md](../../../../CURRENT.md) before using any address. Evidence links point to the audit documents; they stay authoritative. Link texts abbreviate the audit file names (full list under [Sources](#sources)). Function names in the semantic database are mostly `candidate`; the branch/field facts below are what the audits confirmed.

## Overview

- Map: 800x800 coordinate envelope; tiles are addressed by a packed tile ID (`x + rowPrefix[y]`, 320,800 IDs, diamond-shaped rows), not `y*800+x`. Per-tile grids hold flags, heights, building IDs, path regions (PCL) and one **direction byte** per tile (bit d = edge to neighbour d, clockwise from north).
- One global **path manager** at RVA `0x60AD660` owns search mode words, the BFS ring queue, stamps/distances and the **portal table** (gatehouses, ladders) that connects regions.
- A move command flows: cursor `0x8C5F0` / Chore 17 `0x10AE0` -> player wrapper `0x196100` -> **group move `0x11B520`** (or common-group dispatch `0x118E00`) -> per unit **`0x196280`** -> route builder **`0xF4930`** (direct line, BFS ground/moat/Assassin searches, reconstruction `0xE1640`) -> packed 1000-byte route slot per unit.
- The route is consumed by the unit update `0x182B00` -> movement executor **`0x1855A0`**, which checks each new step physically through `0xDCE60` (connection/climb/moat) and `0xDCD60` (type surface restrictions). Search graph and physical step predicate differ.
- Region reachability (`0xE2610`, `0xE2F60`, Assassin `0xE2CA0`) is a coarse macro query over PCL components and portal records; it never proves a tile route or movement permission.
- Cost hot spots: AI group orders (one full BFS per member, budget up to 400,000), Assassin BFS `0xD9C40`, reconstruction failures that trigger a full direction-byte rebuild, and the ordinal member lookup `0x119F90`.

## Behavior

### Route builder `0xF4930`

- Region gate `0xF49C8`: start/target PCL from `0x50EC690`; if they differ and modes `+0x84`/`+0x88` are zero, search only if target region != 0 and `0xE2F60` connects them; otherwise return 0 without writes. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- Ground mode (`+0x80/+0x84/+0x88` = 0): `+0x7C=1`, `+0x155F68=0`; direct attempt (`0xF32B0` profile 0, `0xF3060` otherwise); success `+0xA8++`. Failure: `+0xAC++`, `+0x7C=0`, `0x79C0`, then `0xDAAC0` budget `2*(d+4)^2` (d at `0x34A9F5C`), then `0xDA590` 400,000; any success -> `0xE1640` mode 1. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- `+0x80 != 0` (after skipped/failed direct attempt): straight to `0xDA590` 400,000. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- Moat mode (`+0x84`!=0): no region gate, no direct attempt; `+0xAC++` at `0xF4A2B`; `0xDAAC0` (`0xF4AF5`) then `0xDAFD0` 400,000 (`0xF4B50`); both fail -> return 0 at `0xF4A85`; reconstruction mode 2. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- Assassin mode (`+0x88`!=0): per the 2026-11-25 reading, `0xDA590` with budget `10*(d+4)^2` when region IDs match, `0xD9C40` if that fails or regions differ; reconstruction mode 3 (`0xF4B5A`); zero result returns immediately (no `0xE1640`). Bypasses ordinary region/precheck paths. [confirmed, static; see contradictions] ([GRB](../GROUND_ROUTE_BUILDERS.md), [ARR](../ASSASSIN_RECONSTRUCTION_REPAIR.md), [SIM](../SIM_TICK_SPIKE_PATHING.md))
- Profile 0 refinement: when `+0x94 != 0` after a route, reset, try `0xDB650` (400,000), else `0xDA590`, then `0xE1640` mode 1 (recounts `+0x94`). Profile 1 skips `0xDB650` wall avoidance (`0xF4B94`). [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md), [TUR](../TRAPPED_UNIT_RESCUE_AUDIT.md))
- Large search predicate B (entered tiles, not the start): no `0x10000100` bits, OR flag 2 (Goodsyard), OR building type with nonzero `0x2E68D0` entry. Physical predicate R of `0xDCD60`: no wall/elevated bits, OR `(flags & 0x102)==0x102` with building 0, OR whitelisted building. R is a subset of B. [confirmed, static + isolated execution] ([MSP](../MOVEMENT_SURFACE_PROFILES.md))
- Live profile counts: Large 13 / Default 77 types; class allowed totals 4/16/89/89/89/83. Grunt (type 8) has profile 1; ordinary soldiers normally Default. [confirmed, runtime] ([PTR](../PATHFINDING_TABLE_REPLACEMENTS.md), [TUR](../TRAPPED_UNIT_RESCUE_AUDIT.md), [UCP](../UNIT_COMMAND_PROBE_SCRATCH.md))
- Permission reader `0x181E00`: no callees/branches; reads signed type at `manager+gameId*0x490+0x6E6`, returns `0x32BC48[class*0x5A+type]`. Profile readers `0x18E1E0`, `0x196280`, `0x198ED0` branch on profile 0. [confirmed, disassembly] ([PTR](../PATHFINDING_TABLE_REPLACEMENTS.md))
- An isolated execution of original `0xF4930` on a synthetic grid returned 4 steps (through a wall) for Default and 8 for Large. [confirmed, fixture] ([MSP](../MOVEMENT_SURFACE_PROFILES.md))

### BFS searches and state

- `0xDAAC0`/`0xDA590`: straight step distance +1, diagonal +2, but breadth-first order; end when target dequeued or budget (dequeues) spent; return 0 for start outside 0..799 or unavailable start (`0x3A11EA4`); invalid target caps budget at 500. Native queue order 6,2,0,7,1,4,5,3. [confirmed, static + fixture] ([GRB](../GROUND_ROUTE_BUILDERS.md), [EBP](../ENEMY_BRIDGE_PAIR_INPUTS.md))
- The queue holds 320,800 entries, so a failed search with budget 400,000 exhausts the start's forward component; stamps of the final generation are exactly that component. A closed stamped set (start inside, target outside, no allowed outgoing edge) proves unreachability for every source inside it, even with one-way edges. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md), [UCP](../UNIT_COMMAND_PROBE_SCRATCH.md))
- 89 functions read stamps/distances; the 18 that do not increment the generation clear the arrays (`0x15200`, `0x5BC70`, `0x71670`, `0xE6250`, `0x7490`) or read their own caller's fresh search (`0x11B520` -> `0x124740/0xE0970/0xE0AC0/0xE1D30`; `0x1243D0` -> `0xE1C30`; `0x3BC90` -> `0xEA620`; `0x3C150` -> `0xF2CB0`; `0x1263D0/0x1264D0/0x1265B0/0xCEFC0/0xCF020/0xCF080/0xCF110/0x3BB80/0x3BD50` -> `0xE3590` via `0xE8C20/0xE9500/0xE9610/0xE9720/0xEA3D0/0xEA4E0`; `0x123090/0x1232E0/0xE4FC0` search first). [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- `0x34A9F50` is scratch: all 61 readers of `+0x04..+0x0C` and helpers `0x77C0/0x7600/0x7A80` write first; `0x78E0/0x7890/0x9E00` ignore it. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- `0xDAFD0` edge: unvisited n = v + `0x405EDB0[y*8+d]`; direction bit + height check (heights within 0x10; flag `0x10000000` on n adds `0xC07C0(type)`; building types 0x2D/0x2E shift by 0x5A), or flag rules (`0x48F71B0` bits 8, 30, `0x40000800`, `0xA5014B1`, bit 12 with `0x107160`) reading side tiles d-1 and d+1. No player input. `0xC07C0(0x64CCBB0, building)` depends only on the type word `+0x12E`. [confirmed, static] ([GRB](../GROUND_ROUTE_BUILDERS.md))
- `0xD9C40` climb fallback: even (cardinal) direction, `(flags[v] & 0x4A5014B1)==0` or `0x107160` exception, building layer zero on **both** tiles, IsWall `0x100` on either. Vanilla never accepts a route deeper than 800 steps. [confirmed, static] ([AWS](../ASSASSIN_WEIGHTED_SEARCH_COST.md), [ADC](../ASSASSIN_DIRECT_GATEHOUSE_CLIMB.md))
- `0xD9EA6` is a 14-byte `MOVZX/TEST/JNE 0xD9F2B` block; a masked ordinary bit falls through to the cardinal fallback at `0xD9EB4`, whose wall/special checks can still accept at `0xD9F2B`. [confirmed, disassembly] ([EGA](../ENEMY_GATE_ASSASSINS.md))
- `0xD9C40` callers: `0xE2EB5` (`0xE2CA0`), `0xF4B27` (`0xF4930`), `0x11B8EF/0x11B97E/0x11BDE9` (`0x11B520`), `0x123125` (`0x123090`). Continuations reuse native queue state; a zero flood return does not mean no field was built. [confirmed, static] ([EGA](../ENEMY_GATE_ASSASSINS.md), [ADC](../ASSASSIN_DIRECT_GATEHOUSE_CLIMB.md))

### Reconstruction `0xE1640` and repair

- Mode 3 (`0xE19BB..0xE1A12`): ordinary edge `conn[current] & mask[dir]` (`0xE19C0`); otherwise cardinal climb with building-ID rules (`0xE19D8`, `0xE19F9`) and wall bit on either tile. Mode 1 is ordinary, mode 2 moat. [confirmed, static] ([ARR](../ASSASSIN_RECONSTRUCTION_REPAIR.md))
- Inconsistency: `0xD9C40` expands with the start-side bit, mode 3 tests the target-side tile's bit back toward the start, so one-way connections fail reconstruction. Observed: Assassins leaving their own gatehouse over a drawbridge (drawbridge tile lacks the bit back); 63 failures in one run, whole AI groups in the same tick. [confirmed, runtime replay] ([ARR](../ASSASSIN_RECONSTRUCTION_REPAIR.md))
- Failure: `++manager+0x78`, then `0xDAA50` (~9-10 ms), `0xE49D0(manager,1)`, `0xC3E50`, `0xDE6A0` (about 19 ms per failure; global topology mutation); output stays empty. Vanilla counter: 10 per 60 s on `test_8lordsmiddle`. [confirmed, runtime] ([ARR](../ASSASSIN_RECONSTRUCTION_REPAIR.md), [UCP](../UNIT_COMMAND_PROBE_SCRATCH.md))
- Because best distance is mutated in the loop, for target-first T(d4),R(d3),P(d2),S(d1) it can accept R then S at reduced distance 3, replacing S->P->R->T with a costly S->T climb; candidates two or more steps behind are reachable. [confirmed, static counterexample] ([ADC](../ASSASSIN_DIRECT_GATEHOUSE_CLIMB.md))
- `E1A5A` is the accepted decreasing-distance candidate, `E1ABE` selects it; `E1BB4` also receives the `E1C2D` failure jump (external interior entry into `E1BAC..E1BBE`). [confirmed, disassembly] ([EGA](../ENEMY_GATE_ASSASSINS.md))

### Region topology, portals and gates

- `0xF4540` runs once per tick from game tick `0xCDE60` (from `DLL_RunTick` `0x86680`) at `0xCE1A8`, after the conditional rebuild `0xE49D0` at `0xCE0BD`; AI and unit updates follow. `[0]` is written before each handler, so a freed slot counts until the next pass. [confirmed, disassembly] ([PT](../PORTAL_TABLE.md))
- Start/load normalization `0x71670` writes `[0]=200` at `0x71895` and calls `0xF4540` at `0x71B7B`. ## Open questions and contradictions

- Assassin branch order in `0xF4930`: the 2026-11-25 reading (GRB) says `0xDA590` with `10*(d+4)^2` first when region IDs match, then `0xD9C40`; earlier ARR/SIM describe the field as from `0xD9C40` (or `0xDA590/0xDAAC0` on `+0x80`). Re-read `0xF4930` before relying on either. ([GRB](../GROUND_ROUTE_BUILDERS.md), [ARR](../ASSASSIN_RECONSTRUCTION_REPAIR.md))
- `0x118E00`'s "nonzero field at native `+0x446`" (FMP) is wrong: native `+0xA9E` is typed `+0x442`. Corrected 2026-10-26 in MGA. ([FMP](../FORMATION_MOVEMENT_PERMISSION.md), [MGA](../MANUAL_GROUP_ADMISSION.md))
- `0x118E00`'s `+0x748` store is not the path-flags clear (an early draft said so; flags are typed F2 = native `+0x74E`). ([MGA](../MANUAL_GROUP_ADMISSION.md))
- `0x199CD0` is not a path-buffer memset (older FIRE_EFFECTS description refined 2026-11-15); the clear happens before the builder. ([MTA](../MOAT_TRAVERSAL_ALL_UNITS.md))
- Moat-task word layer is `0x5F011A0` (`0x405EDB0+0x1EA23F0`), not `0x485A770` (corrected 2026-11-17). ([EBG](../ENEMY_BRIDGE_GENERAL_DIAGNOSIS.md))
- Earlier claim that both packed tile IDs must agree at a stationary pose was corrected 2026-11-26 (`+0x73C` is an inactive cache after `0x19BA40`). ([TUR](../TRAPPED_UNIT_RESCUE_AUDIT.md))
- The `0x11E960` control value for `0xDA020` is a **signed** word, not ushort as written in EGC (corrected in EGB). Player 0 queries are intentional (command 36).
- `0x19B820` writes killed `+0x8F8=1`, not dismissal `+0xA48=1` (`0x186D10` disband writes `+0xA48`). ([ULP](../UNIT_LOAD_PLACEMENT_CONTRACTS.md))
- Open: writer of direction-byte changes without a tile report; meaning of `0x51D75F0`; follow-up `0xE04B0`; whether the portal table is serialized; whether a placement chore runs before `0xF4540` in the tick; creators of portal types 5 and 7; when demolition changes building `+0x134`; `+0xBC` readers; trigger of a historical full-health spearman AI110 (UNKNOWN); writer/cadence of some scan inputs beyond `0xD1AD0`; universal seed range; exact `0x3C36B/0x3D70B` AI routine. ([PT](../PORTAL_TABLE.md), [GRB](../GROUND_ROUTE_BUILDERS.md), [SIM](../SIM_TICK_SPIKE_PATHING.md), [ULP](../UNIT_LOAD_PLACEMENT_CONTRACTS.md), [PM](../PATHFINDING_MIGRATION.md))
- Script Extender path-table getters use stride 89 and expose 534 permissions (class rows 2..6 misaddressed); native stride is 90 / 540. This is an SE defect, not Vanilla. Installed interop spells `r_GateState`/`r_GateState2` as bytes `0x2A2/0x2A3`, `+0x428`, `+0x42C/+0x42E` as ushort, while upstream headers use wider fields; use the installed assembly. ([PTR](../PATHFINDING_TABLE_REPLACEMENTS.md), [EGB](../ENEMY_GATE_BUILDING_CONTEXT.md), [EGA](../ENEMY_GATE_ASSASSINS.md))
