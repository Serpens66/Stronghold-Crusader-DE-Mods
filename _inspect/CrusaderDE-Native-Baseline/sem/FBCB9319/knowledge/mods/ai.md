## ExtraFeatures

- **AI moat height** (`AIDefenseRepairRuntime` and AI hook): bypasses the `0x59730` height < 13 branch for AI when installed and logically enabled; does not change candidate fit. **Mapper-105 drawbridge**: suppresses the `0x7870B` height failure for allowed AI only when the full hook transaction is active. Crater Lake prebuild trace 2026-09-23 with the hook active. ([LOBBY](../AIV_LOBBY_SELECTION.md))
- **Defense repair**: pairs `0x51790` with `0x5CD90` and captures the six placement arguments (`AIDefenseRepairRuntime.cs`). (function-claims)
- **KeepBuildRange**: host setting -1..500, default -1; positive values use public `KeepProximityOverride`; applies to humans and AI. RedBird `ManagedValue.SetValue` replaces the top entry and `ClearOverrides` keeps base writes, so the feature releases its value on mission end/disable, reconciles before prebuild and after save restore, restores the predecessor only if the current value still equals its last write; no owner token; avoids redundant writes. Synthetic thread-safety stress only. ([RANGE](../AIV_BUILD_RANGE.md#extrafeatures-api-integration-mod-integration))
- **AI market prices**: `AIMarketVanillaPriceHook.cs` is the source evidence for `0xCEB10/0xCEB90` claims; the current owner of both entries is APIShared's price broker (see `mods/economy.md`).
- **AI flag disease**: `AiFlagDiseaseTracker.cs` observes `0x504F0`. (function-claims)
- Defense settings affect enemy proximity and rebuilding, not range. ([RANGE](../AIV_BUILD_RANGE.md))
