## ExtraFeatures

- **Lord defeat reward suppression / percentage** (1.0.102+): two permanent hooks, reward span `0x15C4EA` (14 bytes, ends `0x15C4F8`) and message span `0x15CA65` (15 bytes, skip to `0x15CA74` when zero). Unconfigured roles run Vanilla. Configured human/AI roles compute 64-bit percentages, add gold directly and goods into incoming entries, then branch to cleanup `0x15C980` with RCX/R12D set; messages split at 900,000,000 (max three). Earlier hook `0x15C477..0x15C487` was rejected (skipped cleanup and kill notification); RedBird 1.5.0 context-flag hazard requires a post-callback TEST. In-game: human Rat reward suppression with victory message kept confirmed 2026-09-26; AI rewards and MP parity open. Statistic RVA derived from operands since 2026-10-27. ([LOOT](../DEFEAT_LOOT.md), [KILL](../KILL_REWARD_PERCENT.md))
- **Periodic gold**: positive amounts through SE `AddIncomingGood` (bounded by Int32.MaxValue minus balance and pending), debits through `SetPlayerGold(max(0, balance+amount))` with Int64 math; never negate Int32 input. Since 2026-11-01 scheduled on APIShared `SimulationTickEvents` (native map tick) instead of the local `getSimTickCount`, which could book on different ticks per peer. Offline only. ([GOLD](../PERIODIC_GOLD.md))
- **Lord HP basis**: captures actual completed Vanilla maxima per player/global identity, applies new settings on reload to the saved basis; old saves explicitly unsupported; Lord-creation Post is only a dirty signal. ([SESS](../EXTRAFEATURES_SESSION_CALLBACKS.md))
- **Woodcutter tree maturity**: one transaction of three spans, candidate search `0x107EC5`/20 (skip to `0x107FEA`), arrival `0x12BFCF`/18 and strike `0x12C1D8`/17 (reset worker via `0x12C03D`/`0x12C2B3`); per-session host choice after APIShared mission start; hook availability is per process, so a one-sided install failure can diverge in MP. ([WTM](../WOODCUTTER_TREE_MATURITY.md))
- **Tree respawn**: snapshots accepted woodland on APIShared `NativeLoaded`, activates at mission start, combines SE deletion notifications with a bounded map-tick reconciliation, plants via SE `CreateEx` stage 0 plus component rebuild; versioned save entry. Fixture: 3,999 sites, 0.0102 ms per sweep, zero allocations (2026-11-07); live load/save/editor/MP acceptance open. ([TREE](../TREE_RESPAWN.md))
- **Worker production percent**: owns synchronized percent and mode policy executed by APIShared's bonus service. (WPB)
- **Popularity Human/AI targeting** (2026-10-25): per-role ordinary coefficients and fear policy selected after resource resolution; classifier uses `r_KeepId`/`r_KeepDoorId` > 0 and SE `IsAIPlayer`; report adapter applies the viewed player's policy. Tests only. ([POPP](../POPULARITY_PARAMETERS.md))
- **AI market prices**: `AIMarketVanillaPriceHook` source evidence for the buy/sell helper claims (function-claims.jsonl); current ownership is the APIShared broker above.

## BugfixesAndQoL

- **EnableTreeBlightDecayFix** (host-only, default/reset true, Recommended under Host / Economy / Fixes): event span `[0x107A6C,0x107A7A)` floors stage-5 progress; growth span `[0x10838E,0x10839C)` lets alive stage-5 woodland bypass felled/health predicates (jump `0x1083B0`, reject `0x108645`). 32-byte native state (enabled, table, game-type, frontend pointers). Covers Vanilla and RandomEvents (`FreeBuild_Event`). Fixture tested 2026-10-25; real gameplay, save/load and MP open. ([BLIGHT](../TREE_BLIGHT_DECAY.md))
- **Miller/Baker pause parity** (host setting): permanent conditional RedBird inline hooks, Miller `0x1383F3..0x138404` (return `0x138405`), Baker `0x139596..0x1395A7` (return `0x1395A8`); disabled gateway replays the original branch. Wheat/hops branches are not replaced. ([PAUSE](../WORKER_PAUSES.md))
- **EnableWorkshopIdleDelayFix** (host, default false): 17-byte inline sites Poleturner `0x13AC85`, Tanner `0x13E39F`; skips the idle exit only when material exists (wood via goods yard, hides or a cow) and work mode is not 1; data gate via one Volatile.Write; relocated signatures refused. Fixture tested; in-game first arrival, fear-break return and host/client open. ([IDLE](../WORKSHOP_IDLE_DELAY.md))
- **Plague popularity correction** at `0xCB57C`: replaces Vanilla's plague contribution in EDX and the accumulator for managed players, keeps zero-herd correction after the last cloud, persists `ManagedPlayerIds`; cloud index revalidates global ID and type 22. Watchdog diagnostics need an observed calculation Pre. No gameplay/MP acceptance. ([PLAGUE](../PLAGUE_POPULARITY.md))
- `AIEconomyProtectionHook` sources the claims for `0xC7D50`, `0x3B1D0`, `0x3B270` (topic ai); a 20-byte reserve hook at `0x3F156` does not overlap the Fixes wheat stub. ([WHEAT](../FIXES_WHEAT_STARTUP.md))

## ImprovedHunters

- Rules: own chickens huntable (owner barriers), reservation heartbeat for rabbit/camel/chicken, rabbits not chased in melee without an order (`0x186952`, `0x11EE64`, `0x18C731`), free corpses, nearer-prey switching, configurable range, herd flight ignoring walled-off threats, Hunter's hut buildable without deer/goats, Tannery meat slider (`TannerMeatPatch` sites `0x13EBF7`, `0x13ED8B`, `0x13EEFB`, `0x13EF38`, `0x13F009`; meat output capacity 250 through APIShared receipts), configurable meat per prey (e.g. `ChickenMeat`; prey type captured at corpse arrival, fixed 2026-11-06) and a Tannery meat yield stub calling `0x18D940` with configured base 1..100. Time base: APIShared native map tick, 40 ticks/s.
- Ownership since 1.2 (2026-11-08): gates, reservation release, query/corpse records moved to APIShared.Wildlife; own `OwnedChickenHuntPatch`, `PreyReservationHeartbeatPatch` and issue-123 capture removed. The Fixes mod's wildlife hook occupies rabbit/camel update entries, which blocked the first heartbeat placement.
- Corridor fix (2026-11-19): final path step kept in continuation; when prey survives within one Manhattan tile a bounded firing-position search precedes the same-target retry.
- Acceptance (single player only): SP-hunters scenarios 2026-11-06/07 passed (own chicken, rabbits, deer, Tannery slider, yield fix, hut button, range, flight, speed stage, free corpses, kind matrix, one-corpse-once); 2026-11-19 startup archers/rabbits observed, release run 020 corridor/crosswall/corner passed 127 steps; perf ~4.5 ms per second on a 10k-unit save. Not observed: real MP, resync, AI Tannery, non-lethal deer arrow, warning-sound absence. ([HUNT](../HUNTER_PREY_RULES.md))
