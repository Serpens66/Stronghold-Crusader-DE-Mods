### Tannery fade-in (building animation transparency)
- Developed as a testmod, now `src/Buildings/NativeTannerFade.cs` (source check 2026-11-27). Final design: 7-byte RedBird NativeX64 `Indirect` detour on updater 0xB10D0; restore the previous Vanilla transparency before each call, call the full updater once, then write visible transparency to +0x11A while phase 0..5 and initial images are active; 64 updater calls fade to raw 0 (about 600-750 ms); one-frame bridge keeps raw 0 on the verified phase-5-to-6 update. Logs only initialization, first callback and errors.
- Earlier revisions: a 6-byte `Indirect` detour on packet writer 0x19D110 changing only the transparency argument, paced by Extender `OnTick` callback count (reached full alpha after 30 callbacks / ~303 ms); a first updater detour with a phase/frame/image filter that never fired (unvalidated). A wrong manager address 0x64CBB0 (instead of 0x64CCBB0) rejected the real tannery until corrected.
- Status: user confirmed the fade and the transition bridge in-game 2026-09-24. ([TANNER_ALPHA.md](../TANNER_ALPHA.md))

### Notification last frame (minimap portrait video)
- Current design (2026-10-23, supersedes speech-generation 2026-10-18 text-owned policies): `NotificationLastFrameFeature` uses nonlooping `**` sources for accepted nonlooping minimap videos, captures Vanilla's wait request and the audio manager; a Stopwatch stamp per accepted request; wait cleared permanently on channel-1 idle, audio-manager replacement or > 20 s (HD parity, strict greater-than). On MediaEnded an active binding holds the frame paused in state 1, otherwise public `RadarME_Ended()` closes it; GuiChecks re-pauses after briefing resume. Text never closes/extends the video; audio is never stopped. No native patch; the native queue 0xFE570 sees the released video flag.
- URI fix (2026-10-23): source guard compares slash-normalized `OriginalString` in addition to `Uri` equality; Script Extender video overrides are resolved via its internal resolver (reflection, signature-validated) before appending `**`.
- `NotificationSpeechPlayback` (skip-load cancellation) keeps the Extender `_SE_` single-path loader override; speech hooks and GUI registrations live for the process; mission end invalidates pending identities via the central lifecycle.
- Validation: `Test-NotificationLastFramePreflight.ps1` + `tests/NotificationPlayback.Tests` (19999/20000/20001 ms boundaries, replacements, briefing, stale HUD). Pending: post-fix in-game run. ([NOTIFICATION_LAST_FRAME.md](../NOTIFICATION_LAST_FRAME.md))

### Engine presentation bridge (merit, achievements, save)
- `src/VanillaPerformance/EnginePresentationBridge*.cs`, `MeritDataLockOptimization.cs`, `AchievementDataOptimization.cs` (source check 2026-11-27). Merit: snapshot refreshed with the regular managed method inside the existing locked run, after native processing and copy, before buffer publication; delivered clones never renew the timestamp; missing snapshot = synchronous original; no snapshot crosses a load or mission boundary. Achievements: tuple applied after lock entry and before `DLL_RunTick`, and flushed inside `SaveSaveGame`'s lock before the native save; unsafe saves and failed transfers retain the tuple; foreign synchronous setters drain older pending tuples first. Uses Harmony prefixes/finalizers and run/save transpilers (PerfProbe compatible). Tests: `EnginePresentation.Tests` (evidence `.work/t/perf-opt/001`). Frame-lag effect not measured in-game. ([ENGINE_PRESENTATION_BRIDGE.md](../ENGINE_PRESENTATION_BRIDGE.md))

### Pause and zoom
- Pause is queued as a synchronized Chore; unpause uses the direct transport so a stopped simulation can resume; authorization, active-human sender validation and main-thread dispatch stay required. Private methods, no public automation API. Existing zoom hooks normalize scale to resolution and change step boundaries; automation should call public `PerfectPixelWithZoom` methods and observe the result. Pause/zoom live acceptance not claimed. ([AUTOMATION_PAUSE_ZOOM.md](../AUTOMATION_PAUSE_ZOOM.md), [AutomatisierungTest.md](../../../../../../AutomatisierungTest.md))
