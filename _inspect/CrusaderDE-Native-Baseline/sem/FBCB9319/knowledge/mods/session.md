## APIShared

### Mission lifecycle (`IMissionLifecycleCapability`)

- Supersedes the former editor-only API completely. Immutable context/notifications, monotonic process-local attempt IDs; initialization phases never replay; only a current fully managed-ready session replays to late observers. End carries last context, last phase, reason and `HasStarted`. Observer exceptions isolated; Vanilla delegates execute once; unpublished failed hook candidates roll back, published services stay process-rooted. ([MISSION_LIFECYCLE](../MISSION_LIFECYCLE.md))
- Start = outer normal return of the interactive root (clients: after packet-2 postLoading). Hooks managed roots (see [Vanilla roots](../vanilla/session.md#managed-completion-screens-and-retirement)); captures `newMapEditor` output for editor creation; requires native and outer bool success for editor load. Observes `GoToScreen`/`NewScene`; the Extender HUD exit hook's synthetic Unload Pre (null pointer) counts as retirement; nested unloads inside an operation are suppressed.
- Mode classification and regular-mod/feature permission tables are defined once in APIShared; the Shared per-assembly adapter (`MissionEvents` / `Shared.GameplaySessionLifecycle`, translating EditorCreated/EditorLoaded without fabricated MapStartEventArgs) updates the gate before feature subscribers. Lobby network authority is available outside missions without permitting gameplay. Startup resources exclude save/editor/replay.
- Legacy Customize-origin fields keep provider schemas: Custom Trail IDs 81..92 with one-based missions; Coop provider trail 0..3 and missions 1..10; built-in Vanilla/Sands missions zero-based. `MissionContext.MissionIndex` is always a known zero-based position; absent evidence does not invent one.
- Status: automated validation in `_inspect/MissionLifecycleValidation/RESULTS.md`; game validation of the unified implementation (real MP, mission-specific features) still required. Earlier editor implementation was observed once (Created/End/Loaded) but that does not validate the unified one.
