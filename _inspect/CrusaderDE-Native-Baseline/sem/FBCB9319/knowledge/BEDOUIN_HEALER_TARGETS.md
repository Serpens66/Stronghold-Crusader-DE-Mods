# Bedouin healer target selection

Native build: `CrusaderDE.dll` SHA-256 `FBCB93195FC7EFCA9BDAC5204852EFDD76F9818F59A6711750D77C9CEF2831E2`, image base `0x180000000`. Static findings below use the semantic decompiler and entry disassembly. Function names remain `candidate` until live confirmation.

- `FUN_1800d1ad0` (RVA `0xD1AD0`) periodically calls `FUN_180181340` with the unit-manager pointer in RCX and player ID 0–8 in EDX. Both direct call sites target the function entry at RVA `0x181340`.
- `FUN_180181340` (RVA `0x181340`) rebuilds each player's unit-ID (`short[10000]`) and global-ID (`int[10000]`) candidate arrays. It scans game IDs 1 through `r_NextUnitId - 1`, requires `AliveState == 2`, native field `GameUnit + 0x29C == 0`, same alliance and nonzero native field `GameUnit + 0x2A0`. Eight type IDs are explicitly skipped: 39/40/41 (Catapult/Trebuchet/Mangonel), 58/59/60/61 (Siege Tower/Ram/Portable Shield/Ballista), and 77 (Arab Ballista). The active list also depends on the native player-owner field at `GameUnit + 0x92` and an alternate game flag. The exact civilian exclusion among these gates is not yet individually proven.
- `FUN_18018de10` (RVA `0x18DE10`) is called only by the Bedouin healer updater `FUN_180174100` (RVA `0x174100`). It reads the above candidate arrays, checks self, injury, `+0x29C`, `+0x458`, matching global ID, range, height and line of sight. It returns an in-range unit ID; for a more distant selected target it orders movement with `FUN_180196280` and changes the healer to state `0x65`, returning zero.
- The healer updater's state 7 verifies target ID/global ID, injury and `+0x29C`; it searches again when invalid. On a healing pulse it adds 10 HP, clamps to maximum and updates percentage and health-bar blocks. It also retargets after a unit reaches maximum HP. `FUN_180188340` checks movement completion and `FUN_180197a10` turns the healer toward the target.
- The Script Extender 2.12.0 `OnUnitHealByBedouinHealer` hook changes the later heal amount; it does not change target selection. Fixes has separate Bedouin-healer creation patches, not a detour at the list-builder entry.

Machine entry contract: RVA `0x181340` begins `48 89 5C 24 10 48 89 6C 24 20`; the installed RedBird NativeX64 backend 1.5.0 copied-entry probe selected `Indirect`, displaced exactly 10 bytes, installed `FF 25` with a valid pointer slot and hook entry, then restored all copied bytes.
