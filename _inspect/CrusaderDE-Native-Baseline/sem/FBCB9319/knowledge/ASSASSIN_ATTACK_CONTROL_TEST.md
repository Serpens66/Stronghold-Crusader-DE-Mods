## Test implementation

Testmods/AssassinAttackControlTest, version 0.1.0, host-only EnableMod/ProtectCapturedGates/PreferCastleAccess default true. Only AI Assassins; own/allied captures protected. Walls, two capturable stone gate types, wooden/postern gates and tower types are obstacle targets. Alternative capture goals are valid, unburning enemy stone gatehouses at Vanilla's center destination; ordinary castle access uses valid routes to the target lord/contact neighborhood. The enemy is resolved from current tribe target, siege target, then verified obstacle owner. Unknown targets do not authorize demolition.

APIShared owns the optional permanent update detour. BugfixesAndQoL only publishes a rooted read-only traversal adapter; no new mainmod setting or active attack logic. No version increment was made for this test feature. APIShared remains 0.4.11; an independent parallel change advanced the mainmod to 1.0.178 and was preserved. The mainmod effective APIShared dependency is now 0.4.11 for the new public contract. New interface/guard registration requires all test participants to install the freshly built packages, even if their version labels already match.

One reusable search worker expands at most 4096 nodes/game tick. Exact topology/policy/goals are validated before each continuation and before orders/fallback. Identical per-player/speed snapshots can be shared; obsolete unit identities and corpse/death records are removed. Incomplete/stale searches never count as no route. Pending units remain idle; stopped searches retry through a guarded state-101 transition. Host switch-off restores only still-owned pending contexts. Completed negative proofs must remain current before damage is allowed.
