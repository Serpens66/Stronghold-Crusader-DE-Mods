# StartConditions

- Set or add starting gold for **human and AI** players
- Configure every starting good individually for **human and AI** players
- Remove, preserve, or multiply the official starting armies for human and AI players
- Add custom additional starting troops to humans/AIs.

## Compatibility and diagnostics

This mod requires the Script Extender and **APIShared 0.5.0 or newer**. Subscribe to APIShared separately when using the Steam modpack. Mod settings indicate when gameplay changes are inactive for a direct mission or Trail launch. Use **Customize** where available to start with those changes; edits made while inactive are saved for later games.

Shared services handle presets and game-mode classification while retaining the existing starting-resource and troop options.

Routine activity is logged at Debug level. Repeated diagnostics are limited to reduce log spam; warnings and errors remain available. No gameplay setting is needed for this change.
