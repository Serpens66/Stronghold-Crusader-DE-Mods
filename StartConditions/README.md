# StartConditions

- Set or add starting gold for **human and AI** players
- Configure every starting good individually for **human and AI** players
- Remove, preserve, or multiply the official starting armies for human and AI players
- Add custom additional starting troops to humans/AIs.

## Compatibility

This mod requires the Script Extender and **APIShared 0.23.0 or newer**. Subscribe to APIShared separately when using the Steam modpack. Mod settings indicate when gameplay changes are inactive for a direct mission or Trail launch. Use **Customize** where available to start with those changes; edits made while inactive are saved for later games.

Starting troop preparation follows the match's simulation time, so multiplayer players use the same timing regardless of their frame rate. All participants need matching modpack and APIShared versions.
