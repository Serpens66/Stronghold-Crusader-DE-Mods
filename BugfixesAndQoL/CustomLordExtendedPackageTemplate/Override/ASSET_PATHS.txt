Examples of logical asset locations below Override:

Assets/GUI/Sprites/your-lord.png
Assets/GUI/Video/your-lord-neutral.webm
fx/speech/your-lord-neutral.ogg
Locales/en-US/fx/speech/your-lord-message.ogg
Locales/<locale>/fx/speech/your-lord-message.ogg

JoinAudioPath and LeaveAudioPath use the full logical path, for example
fx/speech/your-lord-join. AudioPath in a Messages clip uses only the speech name.
VideoPath uses the bare message-video stem, backed by a WEBM in Assets/GUI/Video.
All asset-backed fields are optional. Empty, omitted, or unresolved components
retain the corresponding official CustomMedia component instead of suppressing it.

Locale-aware audio resolves the current locale, then en-US, then the global path.
OGG Vorbis is recommended. WAV must be RIFF/WAVE PCM format 1, mono or stereo,
exactly 44.1 kHz (44100 Hz), 16-bit, and contain a valid non-empty data chunk.
For maximum compatibility, export a conventional PCM WAV with the normal fmt
chunk directly after the WAVE header and no odd-sized metadata chunk before data.
The Script Extender does not resample 48-kHz legacy speech; such WAV files are
rejected at playback even though the uploader transports them.

The complete package may also use other Override assets supported by the Script
Extender Asset API. It may contain root init.lua and relative Lord-AI modules,
root Locales/<locale>/crusader.txt, and Scripts/init.lua for an Asset Mod script.

The uploader copies every regular extra file without an extension allowlist. This
instruction file and the template screenshot will therefore also be uploaded if
they are left in a copied Lord folder. Remove template instructions, screenshots,
source media, archives, conversion projects, executables, DLLs, and backups before
publishing. Keep the final Lord directory limited to intentional package content.
