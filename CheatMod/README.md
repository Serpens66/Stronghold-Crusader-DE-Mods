# CheatMod

The mod's host activation is disabled by default.

- **Endless Extreme Powers** refills the Extreme Powers mana of every living human player to a full bar once per 40 simulation ticks
- The mana updater starts only after the map has finished loading and only while Vanilla Extreme Powers are enabled
- Calls to the Script Extender's `SetLocalPlayerExtremePowersEnabled(...)` API immediately enable or disable the updater as appropriate
- Host settings use the shared preset and multiplayer synchronization system
