# Native update contract

No native hooks or fixed offsets are owned by this testmod. APIShared owns them.
See APIShared/UpdateToNewDLL.md and the current baseline knowledge document
ASSASSIN_DIRECT_GATEHOUSE_CLIMB.md. The observer reads public installed SE fields
only; `_inspect/AssassinGateClimb/verify.ps1` validates their visibility.

On updates re-audit physical states 126..129, gate roof topology, human movement
classification, AI gate action, both native path passes and Fixes target filters.
Do not infer successful direct climbing from a movement command alone.
