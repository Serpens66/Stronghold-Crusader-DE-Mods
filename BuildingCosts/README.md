# BuildingCosts

- Customize the construction costs of every building type: Wood, stone, iron, pitch, and gold
- Modified construction costs apply to both **human and AI** players (beware that this might cause problems for AIs!)

## Compatibility and diagnostics

This mod requires the Script Extender and **APIShared 0.6.0 or newer**. Subscribe to APIShared separately when using the Steam modpack. Mod settings indicate when gameplay changes are inactive for a direct mission or Trail launch. Use **Customize** where available to start with those changes; edits made while inactive are saved for later games.

Building-cost tooltips use coordinated APIShared HUD hooks to improve compatibility with other mods.

Routine activity is logged at Debug level. Repeated diagnostics are limited to reduce log spam; warnings and errors remain available. No gameplay setting is needed for this change.
