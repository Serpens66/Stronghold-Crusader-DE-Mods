# BuildingLimit

- Individual building limits for **human** players: Set a separate maximum for every building type to guarantee a balanced economy on every map, eg. at most 2 stone quarries and 2-3 farms.

## Compatibility and diagnostics

This mod requires the Script Extender and **APIShared 0.9.0 or newer**. Subscribe to APIShared separately when using the Steam modpack. Mod settings indicate when gameplay changes are inactive for a direct mission or Trail launch. Use **Customize** where available to start with those changes; edits made while inactive are saved for later games.

Building-limit tooltips use coordinated APIShared HUD hooks to improve compatibility with other mods.

Routine activity is logged at Debug level. Repeated diagnostics are limited to reduce log spam; warnings and errors remain available. No gameplay setting is needed for this change.
