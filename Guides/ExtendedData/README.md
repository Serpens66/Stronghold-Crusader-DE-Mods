# ExtendedData guides

This directory collects user and developer documentation for `ExtendedData` and the file conventions it supports.

## Contents

- [Mod settings in Custom Trails](Custom%20Trail%20Mod%20Settings.md) — For Trail creators who want to configure compatible gameplay mods per mission and distribute those settings with normal or Coop Trails.
- [Extended Data compatibility for mod authors](Mod%20Compatibilty%20ExtendedData.md) — For mod developers who want their lobby settings to participate in ExtendedData mission presets without referencing `ExtendedData.dll`.
- [Custom Lord packages with Script Extender](CustomLordExtendedPackages.md) — For Custom Lord authors who want to add Script Extender metadata, localized descriptions, media, Lua, or supported Workshop content.
- [Mod-specific data for Custom Lord AICs](ModLordData.md) — For Lord and mod authors using the ExtendedData API to read GUID-namespaced data from `name.modlord.json` sidecars.
- [Mod-specific data for maps](ModMapData.md) — For map and mod authors embedding static GUID-namespaced data as `modmap.json` while retaining Vanilla map compatibility.
